# 模型结果

实验数据与评测产物，模型权重统一位于 `../models/`。目录内的 CSV/JSON 是训练与评测脚本直接写出的原始工件，数值与字段名保持原样。

- `revision_v2/`：12 个对照模型的母体分组嵌套评价、诊断、参数选择、部署元数据、预测与分析结果。
- `combination_v3/`：丰富特征、树/核/神经网络融合及 TabPFN 的筛查、内层选择、外层预测、指标、配对比较和部署元数据。
- `experiments/`、`final_results/`、`deployment/`、`analysis/` 及根目录汇总表：早期实验与画图所用结果。
- `data_audit/`：源数据的质量核对结果；数据划分位于 `../datasets/splits/`。
- `layout_migration.json`：各代码文件的 SHA-256 清单，用于核对产生这些结果时的代码版本。

保留内层候选记录与逐折预测，是为了复核参数选择、组合权重与评价过程。汇总表不能替代原始预测，逐种子算指标后平均与先平均预测再算指标是两种不同口径。

新的实验结果写入新的实验版本目录，不改写既有结果。日志、截图、临时审计与缓存属于本地文件，不随仓库分发。图表由 `plotting/` 下的脚本生成到 `figures/`。
