# 模型结果与复现记录

仅保存可核对的实验数据，模型权重统一在 `../models/`。既有结果按原实验目录层级迁入，数值和文件内容保持不变；历史 JSON 中出现的旧 `artifacts/` 路径属于原始记录，不应为美化路径而改写。

- `revision_v2/`：12 个原模型的母体分组嵌套评价、诊断、参数选择、部署元数据、历史预测与分析结果。
- `combination_v3/`：丰富特征、树/核/神经网络融合及 TabPFN 的筛查、内层选择、外层预测、指标、配对比较和部署元数据。
- `experiments/`、`final_results/`、`deployment/`、`analysis/` 及根目录汇总表：早期实验与画图依赖。
- `data_audit/`：源数据的质量核对结果；唯一生效的数据划分放在 `../datasets/splits/`。
- `layout_migration.json`：本次目录迁移的路径规则和代码迁移前后哈希，用于检查冻结实验与当前代码的对应关系。

保留内层候选记录与逐折预测是为了复核参数选择、组合权重和评价过程。不要只凭汇总表替代原始预测，也不要混淆逐种子算指标后平均与先平均预测再算指标。

新结果只提交经过核对的 CSV/JSON；日志、浏览器输出、截图、报告逐页预览、临时审计和缓存写入 `.cache/`，不提交。生成脚本可能产生说明文件或临时文件，仍须按根目录 README 的推送流程审查。不要覆盖既有实验结果来表示新实验；改变训练方法、数据或协议时使用新实验版本。
