## 打开实际系统

`presentation/` 与 `webapp/`、`models/` 保持同级。已准备项目 Python 环境后，可双击 `Start-Presentation.bat`，或从项目根目录运行：

```sh
uv sync --frozen
uv run --frozen python -X utf8 presentation/launch.py
```

启动器打开 `http://127.0.0.1:8502/presentation/`。保持服务运行，在视频页点击 Open Local SOLAR Studio 打开真实系统。CPU 推理可能慢于原录屏，课堂时间预算使用附带的完整视频。
