## Source checks and corrections

- **Relative improvement.** V2 §6.2, the project README and the brief attach 8.54% and [−0.1219, −0.0082] to the blend against basic ExtraTrees. V2's own reproducible `analysis/results.py` and `results.json` assign these to `paired.rich_vs_basic`. The blend-versus-basic export `paired.basic` gives 10.73% and [−0.1366, −0.0276]. The arithmetic (0.7469 − 0.6668) / 0.7469 also gives about 10.72% using rounded inputs. Slides 08–09 use the unrounded export and label both comparisons.
- **Holdout.** The V2 method table scores the development set. The reserved 33-parent manifest and paper describe a distinct frozen test set. Historical rows in `output/final_metrics.csv` have scores on that test set. The v2 blend's deployment metadata flags its historical holdout as unevaluated and there is no checked-in `output/combination_v3/test_set/test_metrics.json`. No new holdout scoring was run.
- **TreeSHAP and temperature.** The tree chart reports parent-equal means of absolute net group attributions in log-solubility units. V2 interprets numeric temperature as °C. The frozen CSV policy says its physical unit was not independently verified. The pooled value in Fig. 8 uses the same 1,118 rows as the within-pair value; the full-development pooled estimate is a separate result. The prose's clustered interval [0.0121, 0.0186] differs from the exported cluster-robust values (about [0.01198, 0.01878]). Slide 10 displays the parent-bootstrap interval [0.01236, 0.01902], which agrees across v2 text, the plotted source and the JSON. The sensitivity value 0.54013 is the equal-strength partial-R² needed to remove the point estimate under the specified bias model.
- **Feature scope.** The 869-column vector is the rich tree input representation. The 665 retained columns are verified for the explained deployed tree; the report specifies that imputation and variance selection are fitted within training folds. The deployment blend's 75/25 weighting is distinct from fold-specific inner-OOF weights.
- **Application check.** The prediction at 25 is for Lovastatin in acetone. The JSON and the original recording report −0.7270 and 0.1875 mol/L after rounding. Zero API/offline difference indicates agreement between inference paths. The included live Windows CPU capture displays −0.7271 and 0.1875 mol/L on the same case. The main slide keeps the recorded v2 values and shown frame together.
- **Timing and attribution.** The brief's individual times sum to 15:30. Slides 02 and 03 were each shortened by 15 seconds, giving exactly 15:00. The cover gives the members' names in the order supplied by the group.
