1. 先改 0.6 的数字口径表，再改题目；任何数字必须能在 `../Report_final/`、`../presentation/` 或 `../output/` 中找到出处。
2. 主模型口径：0.6668，较基础 ExtraTrees 低 0.0801（10.73%）；8.54% 只用于 Rich ET 阶段。
3. 显著性只说对基础 ExtraTrees 显著；对 Rich ET / TabPFN 的配对区间跨零。
4. 33 个留出母体只描述为未报告的盲测库，不声称已验证。
5. 新增题目沿用现有格式：`### Qxx`、中文回答、English answer、关键数字、可能追问。
